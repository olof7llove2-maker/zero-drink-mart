# 제로 음료 비교 마트 (띠니)

제로음료·단백질음료·단백질쉐이크·식단고기를 단가와 단백질·성분으로 비교하는 정적 사이트입니다.
`index.html` 하나와 `css/`, `js/`, `images/`, `data/` 자산으로 이루어져 있고, 빌드 없이 그대로 열립니다.

- 배포: https://ttini.kr (Vercel, main 브랜치 push 시 자동 배포)
- 상품 데이터: `js/products.js` (203개 상품). `data/products.json`은 같은 데이터의 JSON 사본이고,
  `js/products.js`가 로드되지 않을 때 사이트가 이 파일로 넘어갑니다. 두 파일 내용은 항상 같게 유지합니다.
- 첫 화면의 **마지막 업데이트** 날짜는 상품 카드의 `priceCheckedAt` 중 가장 늦은 날짜에서 계산합니다
  (`js/app.js`의 `latestChecked()`). 그래서 가격을 갱신하기만 하면 날짜도 같이 바뀝니다.
  업데이트 주기 문구는 `SITE.updateCycle`·`SITE.updateCycleNote`에 있습니다(예: 매일 오전 9시·오후 9시 가격 자동 업데이트).
- 세부 분류는 `CATEGORIES`(이름·이모지)와 `PARTS[].filters`(칩 이름·이모지·한 줄 설명)로 그립니다.
  2026-11-16에 `python3 scripts/update_labels_20261116.py`로 이름을 풀네임으로 다듬었습니다
  (이온 → 이온음료, 에너지 → 에너지음료, 애사비 → 애사비(사과식초), 분말 → 분말·티백 등).
- 대분류 5단: `PARTS`(전체 203 · 🥤 제로 음료 70 · 💪 단백질 음료 24(고단백 21 + 두유·저단백 3) · 🥛 단백질 쉐이크 16 · 🥩 식단 고기 62 · 🍕 치팅·간편식 31) → `CATEGORIES`(세부 분류).
  탭에 상품 개수가 함께 표시되고, 세부 분류는 뭉치지 않고 하나씩 나뉩니다.
  (제로: 콜라·사이다·탄산수·생수·차·아이스티·이온음료·에너지음료·애사비(사과식초)·분말·티백 /
   고기: 소고기·돼지고기·닭고기·양고기·오리고기·연어·에어프라이어·조리기구)
- 단백질 음료 세부 필터는 상품별 `proteinType` 값으로 고릅니다
  (`soy` 두유·식물성 · `choco` 초코·커피맛 · `fruit` 과일맛(딸기·바나나) · `plain` 플레인·고소한맛).
  `고단백(20g+)` 는 병당 단백질 20g 이상. 분류를 바꾸거나 추가할 때는
  `python3 scripts/restructure_categories_20261116.py` 로 두 파일(PARTS·proteinType)을 함께 갱신합니다.

## 화면 구조 (v3 · 2026-11-16 개편)

채찍단(cowlr.kr)을 참고해 5탭 구조(홈·카테고리·검색·랭킹·핫딜)로 정리했습니다. `index.html` 하나에서 `?tab=`으로 화면을 바꿉니다.

  (제목 아래 `🔥 전체 · 🥤 제로음료 · 💪 단백질 · 🥩 식단고기 · 🍕 간편식` 칩 — 누르면 아래 카드 레일만 바뀜) →
  💪 단백질 레일 → 전체 상품 목록. 1분 결론 칩·10초 맞춤 추천은 r28에서 없앴습니다.
  가격 기준 시각·조회수 같은 운영 정보는 **푸터 맨 아래 작은 한 줄**로만 둡니다(r26).
- **검색** `?tab=search`: 하단 탭바(모바일)·상단 내비(데스크톱) 가운데 `🔍 검색`. 열면 입력창에 바로 포커스되고,
  입력하는 대로 실시간으로 걸러 단가 낮은 순으로 보여 줍니다. 검색어는 검색 탭에서만 목록을 좁히고
  홈·카테고리·랭킹·핫딜은 늘 전체 상품을 보여 줍니다. `?q=`로 들어오면 검색 탭이 열립니다.
- **카테고리** `?tab=category`: 대분류(전체·제로·단백질·고기) + 종류/용기/성분 필터 + 상품 목록(한 분류만 보이면 한눈에 비교표).
  안쪽 맨 위에 **1줄짜리 쿠팡 기획전 링크**(`#cat-promo`)가 고른 카테고리에 따라 바뀝니다 — 고기→고기역전,
  단백질·쉐이크→건강·저당, 조리기구(고기 › 조리기구)→가전 블랙프라이데이, 그 외(전체·제로·치팅)→식단관리.
  홈 탭에는 띄우지 않습니다(`renderCatPromo()`, 링크는 아버님 파트너스 단축 링크).
- **랭킹** `?tab=ranking`: 부문(제로·단백질·고기) × 기준(100ml·100g당 최저가 / 단백질 20g당 최저가 / 할인율 / 리뷰 많은 순) TOP 10.
  제로 부문의 100ml당 최저가는 생수만 올라오는 것을 막으려고 **종류별 1위**만 모읍니다.

  `저점 대비 +N% ▲` / `평균 대비 -N% ▼`를 표시하고, 오늘부터 기록이 시작된 상품은 `추적 시작`으로 둡니다.
