# 제로 음료 비교 마트 (띠니)

제로음료·단백질음료·단백질쉐이크·식단고기를 단가와 단백질·성분으로 비교하는 정적 사이트입니다.
`index.html` 하나와 `css/`, `js/`, `images/`, `data/` 자산으로 이루어져 있고, 빌드 없이 그대로 열립니다.

- 배포: https://zero-drink-mart.vercel.app (Vercel, main 브랜치 push 시 자동 배포)
- 상품 데이터: `js/products.js` (125개 상품). `data/products.json`은 같은 데이터의 JSON 사본이고,
  `js/products.js`가 로드되지 않을 때 사이트가 이 파일로 넘어갑니다. 두 파일 내용은 항상 같게 유지합니다.
- 첫 화면의 **마지막 업데이트** 날짜는 상품 카드의 `priceCheckedAt` 중 가장 늦은 날짜에서 계산합니다
  (`js/app.js`의 `latestChecked()`). 그래서 가격을 갱신하기만 하면 날짜도 같이 바뀝니다.
  업데이트 주기 문구는 `SITE.updateCycle`·`SITE.updateCycleNote`에 있습니다(예: 매일 오전 9시·오후 9시 가격 자동 업데이트).
- 세부 분류는 `CATEGORIES`(이름·이모지)와 `PARTS[].filters`(칩 이름·이모지·한 줄 설명)로 그립니다.
  2026-11-16에 `python3 scripts/update_labels_20261116.py`로 이름을 풀네임으로 다듬었습니다
  (이온 → 이온음료, 에너지 → 에너지음료, 애사비 → 애사비(사과식초), 분말 → 분말·티백 등).
- 대분류 4단: `PARTS`(전체 125 · 🥤 제로 음료 52 · 💪 단백질 음료·쉐이크 30 · 🥩 식단 고기·조리 43) → `CATEGORIES`(세부 분류).
  탭에 상품 개수가 함께 표시되고, 세부 분류는 뭉치지 않고 하나씩 나뉩니다.
  (제로: 콜라·사이다·탄산수·생수·차·아이스티·이온음료·에너지음료·애사비(사과식초)·분말·티백 /
   고기: 소고기·돼지고기·닭고기·양고기·오리고기·연어·에어프라이어·조리기구)
- 단백질 음료 세부 필터는 상품별 `proteinType` 값으로 고릅니다
  (`soy` 두유·식물성 · `choco` 초코·커피맛 · `fruit` 과일맛(딸기·바나나) · `plain` 플레인·고소한맛).
  `고단백(20g+)` 는 병당 단백질 20g 이상. 분류를 바꾸거나 추가할 때는
  `python3 scripts/restructure_categories_20261116.py` 로 두 파일(PARTS·proteinType)을 함께 갱신합니다.
  (이 스크립트는 `const PARTS` 중 **첫 번째** 블록만 바꿉니다. 2026-11-16에 뒤에 남아 있던
  예전 `const PARTS` 사본을 `scripts/update_labels_20261116.py`로 지워, 이제 선언은 하나뿐입니다.)
  `전체`에서는 단백질·제로 음료가 먼저, 고기·조리기구가 맨 뒤에 옵니다.
- 고기·조리기구 43종(소 10 · 돼지 10 · 닭 10 · 양 2 · 오리 3 · 연어 3 · 조리기구 5)은 `data/meat-candidates.json`(초기 27종)과
  `data/meat-airfryer-candidates.json`(2026-11-17 추가 13종) 원본을 `scripts/merge_meat_products.py`(초기)·
  `scripts/merge_meat_airfryer_20261117.py`(추가분)로 합칩니다. 후자를 다시 돌려도 13종은 중복으로 들어가지 않습니다.
- 에어프라이어 조리 팁: 상품에 `airfryerTip`(카드 한 줄 표기, 예: `에프 200℃ 6분→뒤집어 4분`)이 있으면
  카드의 단백질·지방 줄 아래에 작은 한 줄로 보이고, 마우스를 올리면 `airfryerTipNote`(레스팅·주의사항까지 담은 원문)가 툴팁으로 나옵니다.
- 구매 링크: 각 상품의 `affiliateUrl`만 사용합니다. 공유 버튼은 제휴 링크가 아니라 마트 주소를 공유합니다.
- 홈 화면 아이콘: `python3 scripts/make_icons.py` (민트 배경 + 흰 'ㅌ' 캐릭터).
- 배경음악(BGM): 헤더 우측 `🎧 BGM` 버튼(`js/bgm.js`)으로 `audio/lofi-bgm.mp3`(105초 루프)를 켜고 끕니다.
  기본 OFF·볼륨 0.25·무한 루프이고, 클릭할 때만 재생합니다(자동재생 없음). iOS처럼 `audio.volume`이 듣지 않는
  브라우저는 WebAudio 게인으로 볼륨을 맞춥니다. 음원 출처·라이선스는 `audio/README.md`에 있습니다.

## 화면 구조 (v3 · 2026-11-16 개편)

채찍단(cowlr.kr)을 참고해 4탭 구조로 정리했습니다. `index.html` 하나에서 `?tab=`으로 화면을 바꿉니다.

- **홈** `?tab=home`(기본): 히어로(마지막 업데이트·매일 오전 9시·오후 9시 주기·2줄 소개) + 검색 + 바로가기/공유 + 오늘 특가 3개 + 전체 상품 목록.
- **카테고리** `?tab=category`: 대분류(전체·제로·단백질·고기) + 종류/용기/성분 필터 + 상품 목록(한 분류만 보이면 한눈에 비교표).
- **랭킹** `?tab=ranking`: 부문(제로·단백질·고기) × 기준(100ml·100g당 최저가 / 단백질 20g당 최저가 / 할인율 / 리뷰 많은 순) TOP 10.
  제로 부문의 100ml당 최저가는 생수만 올라오는 것을 막으려고 **종류별 1위**만 모읍니다.
- **핫딜** `?tab=hotdeal`: 할인율 높은 순 / 60일 저점 대비(최저가 +30% 안쪽만). 카드마다 판매처·현재가·할인율·저점 배지와 `[상품 확인]`(제휴 링크)·`[🔗 링크 복사]`·`[📊 가격 추이]` 버튼.
- **가격 기준** `?basis=per100ml|per100g|protein20`: 카드의 대표 단가와 정렬을 바꿉니다. 단백질 20g당 가격은
  병·1회분 가격 ÷ 1회 단백질(g) × 20, 고기는 100g당 가격 ÷ 100g당 단백질 × 20(부위 표준값이라 '추정' 표시)입니다.
- **출처 체크박스** `?src=coupang,toss`: 쿠팡/토스 상품만 골라 봅니다. `platform`이 없는 상품은 쿠팡으로 봅니다.
- **60일 저점 배지**: `data/price-history.json`에 관측 기록이 있는 상품만 `60일 최저가!` / `저점 근접 +N%` /
  `저점 대비 +N% ▲` / `평균 대비 -N% ▼`를 표시하고, 오늘부터 기록이 시작된 상품은 `추적 시작`으로 둡니다.
- 기존 URL(`?p=` 상품 강조, `?q=` 검색, `?part=`·`?f=`·`?pack=`·`?ing=`)은 그대로 동작합니다.

## 가격 추이·비교 분석

- 카드마다 `📊 가격 추이·비교` 버튼이 있고, 누르면 가격 그래프와 비교 분석이 열립니다.
- 비교 분석(카테고리 평균 100ml당 가격, 순위, 정가 대비 할인)은 `data/products.json`만으로 계산합니다.
- 가격 이력은 `data/price-history.json`입니다. **없는 값을 만들지 않습니다.**
  - 과거 이력은 공개 가격추적 사이트(쿠프라이스, couprice.co.kr)가 쿠팡 판매가를 다시 확인해 남긴
    관측 기록(최근 60일)만 씁니다. 기록의 itemId/vendorItemId가 우리 상품과 다르면 쓰지 않습니다.
  - 과거 기록이 확인되지 않은 상품은 `2026-11-16 추적 시작` 상태로 두고, 그날 확인한 가격 한 점만 남깁니다.
- 갱신: `python3 scripts/update_prices.py` (내부적으로 `scripts/fetch_price_history.py` 실행)
  - 쿠팡 상품의 관측 이력을 다시 받아 병합하고, `data/products.json`의 확인 가격을 오늘 관측점으로 추가합니다.
  - 갱신 뒤 `git add data/price-history.json && git commit && git push` 하면 배포됩니다.

## 단가 계산기 · 5단계 등급 (2026-11-17)

- **단가 계산기**: 상단 🧮(헤더·홈 배너·푸터) → 모달. 딜 문구를 붙여넣고 `문구 읽기`를 누르면
  가격·배송비·용량·수량을 읽어 `100ml당·100g당 + 개당 + 단백질 20g당`을 계산하고 등급을 판정합니다.
  계산식은 `js/grade.js`(등급·시세·파싱) + `js/calc.js`(모달 UI)에 있고, 같은 계산을
  `python3 scripts/verify_grade.py`가 파이썬으로 다시 계산해 대조합니다.
- **5단계 등급**: `역대급` -20%↓ / `대박급` -12%↓ / `중박급` -5%↓ / `쏘쏘` ±3% / `비쌈` 3%↑.
  비교 기준(평소 시세)은 **같은 용기(캔·소형 페트·대용량·분말·100g) 안에서 같은 브랜드 상품 단가의 중간값**입니다.
  브랜드 표본이 2개 미만이면 같은 용기의 **분류 시세**(표본 3개 이상)를 씁니다.
  - 왜 용기를 나누나: 펩시 1.5L 페트(110원/100ml)와 355ml 캔(186원)을 한 평균에 넣으면 캔이 전부 `비쌈`으로 오판됩니다.
- **14일 규칙**: `data/price-history.json`의 실제 관측 기록이 **14일 이상**(관측 5회 이상) 쌓인 상품만 5단계 배지를 붙입니다.
  그 미만은 기존처럼 `추적 시작` 등으로 두고, 가격 추이 모달에도 "기록이 쌓이면 자동으로 붙는다"고 적습니다.

## 웹푸시 최저가 알림 (`api/`, `sw.js`)

- 개인정보를 받지 않습니다. 저장하는 값은 브라우저가 만든 **구독 객체(endpoint·키)**, 관심 상품 ID, 목표가,
  마지막 발송 시각뿐입니다(전화번호·이메일·이름 없음). 목표가는 이 브라우저(localStorage)에도 함께 둡니다.
- 파일: `sw.js`(푸시 수신·클릭 시 `/?p={id}` 이동, 사이트 파일 캐시는 하지 않음), `js/push.js`(카드 🔔·모달 UI),
  `api/push-vapid.js`(상태·공개키), `api/push-subscribe.js`(POST 구독 / DELETE 해제), `api/push-check.js`(목표가 도달 검사·발송).
- 저장소: **Upstash Redis(Vercel Marketplace) REST**. 아래 환경변수가 자동으로 들어오면 그대로 씁니다.
  - `KV_REST_API_URL` · `KV_REST_API_TOKEN` (또는 `UPSTASH_REDIS_REST_URL` · `UPSTASH_REDIS_REST_TOKEN`)
- VAPID: 공개키는 `api/_lib.js`에 함께 있고, **개인키만 환경변수** `VAPID_PRIVATE_KEY`로 넣습니다.
  `VAPID_SUBJECT`(기본값 `https://zero-drink-mart.vercel.app`)는 필요할 때만 바꿉니다.
- 발송 주기: `vercel.json`의 cron `20 0 * * *`(UTC) = 매일 09:20 KST. 아침 9시 가격 갱신·배포 뒤에 돕니다.
  수동 점검: `GET /api/push-check?dry=1` → 발송 없이 조건에 맞은 구독만 알려줍니다.
  `CRON_SECRET`을 넣으면 `Authorization: Bearer <CRON_SECRET>` 없는 호출은 401로 막힙니다.
- 저장소나 개인키가 없으면 `/api/push-vapid`가 `configured:false`를 돌려주고, 사이트의 🔔 버튼은
  "알림 서버를 켜는 중" 안내를 보여줍니다(구독을 흉내 내지 않습니다).
- 아이폰은 **홈 화면에 추가한 뒤**(iOS 16.4+)에만 웹푸시가 됩니다. 사이트는 그 경우 설치 안내로 안내합니다.
